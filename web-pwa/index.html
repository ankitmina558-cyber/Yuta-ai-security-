24/7 Sticker Moderation + Web PWA + Android APK ($0 बजट)

          

            1. असली 24/7 Sticker Monitoring (Cloudflare Worker + D1 SQLite): बिना किसी पेड सर्वर या PC के, Cloudflare Worker फ्री टियर पर Telegram Webhook 24/7 चलता है। हर स्टिकर sticker_queue में जाकर बैकग्राउंड में स्कैन होता है ताकि ग्रुप मैसेज कभी स्लो न हों।


            2. Sticker Formats & Free Limits:

               • Static WEBP: सीधे स्कैन होता है।

               • Animated TGS: ये Lottie JSON होते हैं, इसलिए Telegram द्वारा दिया गया Thumbnail फ्रेम स्कैन होता है। Thumbnail न होने पर इसे SAFE नहीं माना जाता, बल्कि UNCERTAIN मार्क करके Admin को भेजा जाता है।

               • Video WEBM: Android ऐप MediaMetadataRetriever से फ्रेम निकालता है और Cloudflare Worker Thumbnail फ्रेम या सुरक्षित Admin फ़ॉरवर्ड का उपयोग करता है (फ़्री Worker में FFmpeg नहीं होता)।


            3. Web PWA + Android APK (com.yuta.ai): दोनों एक ही Shared Cloudflare Worker URL और D1 डेटाबेस का उपयोग करते हैं। Telegram Bot Token या Gemini Key कभी Frontend या APK में नहीं डाली जाती।
